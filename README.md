# cy8er.dev

A minimal portfolio website for `cy8er.dev`, built with Vite.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `/index.html` – application entry point
- `/src/main.js` – page content
- `/src/style.css` – layout and styling
- `/public/favicon.svg` – site icon
